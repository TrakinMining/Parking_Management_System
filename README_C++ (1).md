# Smart Parking Management System (C++ OOP Mini Project)

A menu-driven console application written in C++ that manages a small
parking lot using Object-Oriented Programming.

**Submitted by:** Keshav Saini (UID: 25BCD10101)
**Submitted to:** Mr. Jitendra Kumar, Professor
**Submission date:** 21 October 2026

## Features
- Park Cars, Bikes and Trucks in a 5-slot lot
- Duplicate number-plate and "lot full" checks
- Parking ticket with fee on exit (Car Rs.20/hr, Bike Rs.10/hr, Truck Rs.40/hr + Rs.50)
- Live parking status and daily earnings report

## OOP concepts used
Encapsulation, abstraction (abstract class), inheritance, polymorphism
(virtual functions), constructors/destructors, static member, friend
function and operator overloading.

## How to compile and run
```
g++ -std=c++11 parking_system.cpp -o parking
./parking          # on Windows: parking.exe
```
